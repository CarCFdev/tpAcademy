This project was developed in Node.js and is focused on web scraping.
Its goal is to collect information from different websites that publish programming language rankings, in order to compare them with each other.

The project uses scripts that access web pages, extract relevant data, and store it in files for later analysis. This makes it possible to identify similarities and differences between rankings and obtain a general overview of the most used programming languages during the year 2025.

The code is organized into different JavaScript files, each responsible for retrieving information from a specific source. This structure improves readability, maintenance, and allows the project to be easily extended to new websites in the future.
